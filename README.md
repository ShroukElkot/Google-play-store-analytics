# Google-play-store-analytics
Built a scalable big data pipeline using Apache Spark and Delta Lake for app analytics, ETL, and performance optimization. 
- Built a scalable Big Data pipeline on Databricks using Apache Spark and Delta Lake (Medallion Architecture) for ETL, large-scale EDA, and KPI aggregation with ACID guarantees. 
- Applied Spark optimizations to improve performance and handle data skew across app install and rating datasets.
